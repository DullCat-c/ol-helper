# ol-helper

`ol-helper`是一个轻量级的SDK，基于`OpenLayers`开发，基于`TypeScript`开发。用于快速开发地图应用,它提供了简单易用而且完全兼容原生`OpenLayers`的api,方便开发者快速上手。


## 主要功能:
1.创建地图,创建地图并且集成了天地图地图
2.渲染图层和要素,支持唯一图层,自更新图层,临时图层的创建,内置高亮图层
3.选择地图元素,
4.绘制和编辑,hook函数创建绘制和编辑事件



## 特点
- 轻量：打包体积非常小
- TypeScript 支持：提供强类型支持，开发体验更友好。
- 跨框架：适用于各种框架。
